Release Notes
current: v0.7.0-rc.1 · pre-release
v0.7.0
rc.1Catalog expansion, measured faceplates, validation data (pre-release). Six new models — generic 1U/2U/4U servers, a vertical 0U PDU, a 1U blanking panel, and BH Chassis [MC13-LE3]. The EX4200-48T gains front and rear skins with all 48 access ports anchored to their real cages, and the AP7911B was rectified from a 3/4 product shot to a true front elevation so its outlet grid could be measured. Chassis and motherboard are now two layers: a reusable plate with the I/O window punched through, and the board's own photo behind it. Every model carries the facts a layout check needs — PSU count, airflow, PDU capacity — with unsourced numbers returned flagged as estimates. The 3D editing suite is not in this build.
v0.6.7Airflow & image quality (patch). The QFX5100-48T is AFO — front-to-back, intake at the port face — so its rear FRUs now carry the same AIR OUT orange as the QFX5200 and the fan and PSU labels read AFO. Airflow direction is a catalog field shown on the spec line rather than something you read off the photo. All four switch faceplates resampled to 4096 px with edge sharpening, and catalog.js made re-entrant so the console stays clean across every tool.
v0.6.6QFX5100-48T skin (patch). Front and rear photo skins for the QFX5100-48T, with all 54 front ports anchored to their real cages — 48× 10GBASE-T in three blocks of 16 plus the 6 QSFP+ uplinks — measured off the panel rather than laid out procedurally. Rear FRU panel mapped: C0 RJ-45 and console stacked centre, the C0-fiber and C1 SFP cages left, USB right.
v0.6.5Local-file fix (patch). Opening the toolkit straight from disk (double-click, no server) left the Port Catalog empty and the 3D scene stuck loading — browsers block module imports from local files. catalog.js is now a plain script every page loads directly, so the whole toolkit runs from a plain folder, GitHub download included.
v0.6.4Performance (patch). 3D CPU use cut sharply: shadow map renders once instead of every frame, ~30fps idle governor (full 60fps while interacting), hover raycasts throttled, pixel ratio capped at 1.5×, LED churn reduced. Section labels draw on top of the rack — no more clipping — and named servers lead with their hostname on the faceplate, model as the sub-line.
v0.6.3Rear fans & PSUs (patch). Switch rear panels now render their FRU modules: dual PSUs with inlet, grille and status LED, plus a spinning fan-tray bank — QFX5200 shows its documented five fan trays and two power supplies; other models show a generic redundant bank until doc-level counts are confirmed. Toolkit re-packaged as standalone files.
v0.6.2Verified hardware (patch). Every catalog.js spec re-checked against official docs — Juniper QFX5200/EX4200 hardware guides, the QFX5100 datasheet, APC's AP7911B specs. Mgmt, console and USB moved to the rear FRU panels on all three Juniper models; the EX4200 gains its dual Virtual Chassis ports, the PDU its L6-30P input cord. Port Catalog now draws front and rear panels, the 3D places rear ports on the hot-aisle face, and unsourced depths read "TBC" instead of a guess.
v0.6.1Panel look (patch). Hub rebuilt in the ReliableSite dedicated-panel style — dark top bar with two-tone wordmark, icon sidebar with section labels, header-strip cards, Poppins type. Orange brand accent applied across all four tools, icons added to My Tools, toolkit renamed cabinetminister.
v0.63D wiring. 3D faceplates are generated from catalog.js, so every addressable port exists at its real position. Hover a port for address, type, group and wired status; click to arm it (cable class auto-suggested), click a compatible destination to run the cable — data↔power mismatches rejected. Cables follow the site color code (yellow IPMI, green public, orange private, red power), route power down the left channel and data down the right, and save to the same wiring store Connections reads. Click a cable to zoom or delete.
v0.5General planner. CR8-specific naming stripped so the toolkit serves any cabinet build-out; the planner starts from a single empty 47U cabinet plus the reusable template; ReliableSite color profile introduced across the tools.
v0.43D environment + hub. three.js data-center hall — 47U rack row, hot/cold aisles, perforated tiles, overhead cable tray, orbit with deep zoom, section labels — plus this hub with live stats from saved layouts.
v0.3Connections. Port→port and PDU-outlet→PSU mapping on real catalog addresses; per-device port usage, per-PDU load, cable labels, CSV patch-schedule export, JSON save/open.
v0.2Hardware catalog. catalog.js becomes the single source of truth — each model declares its size and port groups, generating addressable ports (et-0/0/12, C13-7, …) rendered as clickable faceplates.
v0.12D planner. Dual-sided 47U rack elevation — cold and hot slots fill independently — with click-to-add, drag, span, rename, auto-save and JSON save/open.

Versioning: new features bump the minor (0.x); fixes, reskins and data corrections bump the patch (0.x.y). v1.0 is reserved for a release the team signs off on — confirmed BH chassis I/O plate, the real Supermicro model in the catalog, and photo-textured 3D skins.
